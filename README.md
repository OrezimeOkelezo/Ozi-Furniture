# Ozi Furniture

A responsive furniture catalogue and demo storefront for Ozi Furniture.

## Included
- Responsive homepage and furniture collection
- Category filters and live product search
- Product bag saved in the visitor's browser
- Custom project request form that downloads a shareable request summary
- Mobile navigation and slide-out bag

## Run locally
Open `index.html` in a browser. No build step is required.

## Important setup notes
- Product photography is loaded from Unsplash and Google Fonts are loaded externally, so those features need an internet connection.
- Product names and imagery are sample catalogue content. Replace them with Ozi Furniture's actual products and approved photos.
- The bag and checkout are a front-end demo. No payment is processed and no order is submitted to a server.
- The quote form creates a text summary on the visitor's device. To receive enquiries automatically, connect a backend/database and a trusted email or messaging service.
- Do not add payment credentials or private API keys to front-end files.

## Deploy
The site can be published with GitHub Pages: in the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
