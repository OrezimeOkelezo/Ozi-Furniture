# Ozi Furniture

A responsive furniture storefront for Ozi Furniture, with a focused product catalogue and WhatsApp enquiries.

## Catalogue
Seven distinct product concepts with seven unique, original AI-generated product photographs: modern plywood wardrobe, fluted TV console, upholstered cloth bed, plywood kitchen cabinets, three-seater couch, dining table with six chairs, and plywood display shelving.

The photographs are illustrative design concepts, not evidence of completed Ozi Furniture jobs or confirmed stock. Replace them with the business's own photographs when available.

## Features
- Responsive catalogue with category filters and product search
- Product bag saved in the visitor's browser
- WhatsApp enquiry flow for selected items and custom projects
- Direct phone, WhatsApp, email and shop address links

## Design references
The UI direction uses the user's saved references for e-commerce and interface design: Bagisto and the saved eCommerce projects for catalogue patterns; Ant Design and UI UX Pro Max for consistent interface hierarchy; and Google Model Viewer, Vanta, and the saved 3D portfolio/scroll-animation projects as inspiration for restrained visual presentation. The site is a lightweight original HTML/CSS/JavaScript implementation, not a copy of those repositories.

## Run locally
Open `index.html` in a browser. No build step is required.

## Enquiries and deployment
Product bag and custom project forms prepare WhatsApp messages. The customer must press Send in WhatsApp. This website does not process card payments or provide a server-side order dashboard. To deploy, import the repository in Netlify and set the publish directory to the repository root; no build command is needed.
